สามารถทำได้แน่นอนครับ! ปกติเวลาเราสั่งรันไฟล์ server.js ด้วย Node.js บน Windows มันจะเปิดหน้าต่าง Command Prompt (จอดำๆ) ขึ้นมาค้างไว้ ซึ่งอาจจะเกะกะสายตาเวลาใช้งานจริง

วิธีที่จะทำให้กดเปิดโปรแกรมแล้ว ซ่อนหน้าต่างไปทำงานเบื้องหลัง (Background Process) ทำได้ง่ายๆ 2 วิธีครับ เลือกวิธีที่สะดวกได้เลย

วิธีที่ 1 ใช้ไฟล์ VBScript (ง่ายที่สุด ดับเบิ้ลคลิกแล้วซ่อนเลย)
วิธีนี้ไม่ต้องติดตั้งอะไรเพิ่ม อาศัยฟีเจอร์ที่มีอยู่ใน Windows อยู่แล้วครับ

ในโฟลเดอร์เดียวกับไฟล์ server.js ของคุณ ให้คลิกขวา  New  Text Document

ตั้งชื่อไฟล์ว่า start_api.vbs (ระวังอย่าให้มี .txt ต่อท้าย)

คลิกขวาที่ไฟล์ start_api.vbs เลือก Edit (หรือ Open with Notepad) แล้ววางโค้ดด้านล่างนี้ลงไป

VBScript
Set WshShell = CreateObject(WScript.Shell)
WshShell.Run cmd c node server.js, 0, False
กด Save

วิธีใช้งาน หลังจากนี้เวลาจะใช้งาน ให้ ดับเบิ้ลคลิกที่ไฟล์ start_api.vbs แทนครับ ระบบจะรันเซิร์ฟเวอร์อ่านบัตรขึ้นมาทำงานเบื้องหลังทันที โดยไม่มีหน้าต่างใดๆ เด้งขึ้นมาเลย

(หมายเหตุ หากต้องการปิดโปรแกรมที่ซ่อนอยู่ ให้กด Ctrl + Shift + Esc เพื่อเปิด Task Manager แล้วหาโปรแกรมชื่อ node.exe จากนั้นคลิกขวาเลือก End Task ครับ)

วิธีที่ 2 ใช้โปรแกรม PM2 (เป็นระบบที่สุด เหมาะสำหรับคลินิก)
วิธีนี้จะมืออาชีพกว่า นิยมใช้ในเซิร์ฟเวอร์จริง เพราะสามารถสั่งให้มัน เปิดอัตโนมัติ ทันทีที่เปิดคอมพิวเตอร์ได้ด้วยครับ

เปิดหน้าต่าง Command Prompt ปกติขึ้นมาก่อน

พิมพ์คำสั่งติดตั้งตัวจัดการโปรแกรมเบื้องหลัง (ทำแค่ครั้งแรกครั้งเดียว)

Bash
npm install -g pm2
เมื่อติดตั้งเสร็จ ให้เข้าไปที่โฟลเดอร์โปรเจกต์ของคุณ แล้วพิมพ์คำสั่งรัน

Bash
pm2 start server.js --name ThaiCardReader
ผลลัพธ์ โปรแกรมจะเข้าไปทำงานเบื้องหลังทันที และจะมีตารางสรุปสถานะสีเขียวๆ ขึ้นมาให้ดูว่ารันอยู่

อยากดูสถานะ พิมพ์ pm2 status

อยากดู Log (ข้อความตอนเสียบบัตร) พิมพ์ pm2 logs ThaiCardReader

อยากปิดโปรแกรม พิมพ์ pm2 stop ThaiCardReader

แนะนำให้ใช้ วิธีที่ 1 ถ้าต้องการแค่ดับเบิ้ลคลิกแล้วใช้งานเลยง่ายๆ ครับ แต่ถ้าอยากตั้งค่าให้คอมพิวเตอร์หน้าเคาน์เตอร์รันโปรแกรมนี้เองทุกครั้งที่เปิดเครื่อง แนะนำให้ใช้ วิธีที่ 2 ครับ!
