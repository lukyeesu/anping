# Anping Smart Card Agent (Android Native APK)
**แอปตัวกลางอ่านบัตรประชาชน USB CCID สำหรับใช้งานบนแท็บเล็ต / สมาร์ตโฟน Android ของอันผิงคลินิก (Offline 100%)**

---

## 📌 คุณสมบัติหลัก (Key Features)

1. **ต่อตรงอุปกรณ์ได้ทันที (Direct OTG Connection):** เสียบเครื่องอ่านบัตรประชาชน USB (100–300 บาท) เข้ากับแท็บเล็ต Android ผ่านหัวแปลง Type-C OTG ใช้งานได้ทันทีโดยไม่ต้องพึ่งพาคอมพิวเตอร์
2. **ความปลอดภัยระดับสูงสุด ป้องกันข้อมูลรั่วไหล 100% (Zero-Leak Security):**
   * ไม่มีโค้ดส่งข้อมูลออกอินเทอร์เน็ตภายนอก
   * ให้บริการเฉพาะภายในเครื่องตนเองผ่าน **Loopback Interface `127.0.0.1:8181`** เท่านั้น
   * ข้อมูลไม่ถูกจัดเก็บลงหน่วยความจำถาวรหรือไฟล์ใดๆ ของแท็บเล็ต
3. **ระบบ Auto-Launch เมื่อเสียบสาย:**
   * ตัวแอปจะเปิดทำงานเบื้องหลังอัตโนมัติเมื่อมีการเสียบสาย USB OTG
4. **รองรับการปลุกแอปอัตโนมัติ (Deep Link):**
   * หน้าเว็บคลินิกสามารถส่งคำสั่งปลุกแอปได้ผ่าน URL Scheme `anpingagent://open`

## 🛠 วิธีการคอมไพล์เป็นไฟล์ APK (How to Build APK)

### วิธีที่ 1: คอมไพล์ผ่าน Android Studio (แนะนำและง่ายที่สุด)
1. เปิดโปรแกรม **Android Studio**
2. เลือกเมนู **File > Open...** แล้วเลือกโฟลเดอร์ `android-card-agent`
3. รอระบบโหลด Gradle และ Sync โปรเจกต์จนเสร็จสมบูรณ์
4. ไปที่เมนูแถบด้านบน: **Build > Build Bundle(s) / APK(s) > Build APK(s)**
5. เมื่อเสร็จสิ้นจะมีหน้าต่างขึ้นมา ให้กดปุ่ม **"locate"** เพื่อเปิดดูไฟล์ติดตั้ง APK:
   * ไฟล์จะอยู่ที่โฟลเดอร์: `app/build/outputs/apk/debug/app-debug.apk`
   * สามารถเปลี่ยนชื่อไฟล์เป็น `anping-card-agent.apk` เพื่อนำไปใช้งานได้ทันที

### วิธีที่ 2: คอมไพล์ผ่าน Command Line (สำหรับเครื่องที่มี Gradle/Android SDK)
```bash
cd android-card-agent
./gradlew assembleDebug
```

## 📲 วิธีติดตั้งบนแท็บเล็ต Android

1. นำไฟล์ `anping-card-agent.apk` คัดลอกลงในแท็บเล็ต หรืออัปโหลดไว้บน Google Drive / Cloud ของคลินิก
2. กดเปิดไฟล์ `.apk` บนแท็บเล็ต
3. หากแท็บเล็ตแจ้งเตือนความปลอดภัย ให้กดยืนยัน **"อนุญาตให้ติดตั้งจากแหล่งนี้ (Allow from this source)"**
4. เสียบเครื่องอ่านบัตรประชาชน USB เข้ากับแท็บเล็ตผ่านสายแปลง Type-C
5. เมื่อหน้าจอขึ้นถามยืนยันสิทธิ์ USB ให้ **ติ๊กถูก "เปิด Anping Card Agent ทุกครั้งที่เชื่อมต่ออุปกรณ์นี้"** แล้วกด **OK**
6. เปิดหน้าเว็บคลินิกบนเบราว์เซอร์ Chrome และกดปุ่ม **"อ่านข้อมูลจากบัตร (Smart Card)"** เพื่อใช้งานได้ทันที!
